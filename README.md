# Portfolio Website

A personal portfolio website built with **React.js**, showcasing my skills, projects, and resume.Deployed on **Vercel** for live access.

## Live Demo

[View Live Portfolio](https://portfolio-9aouslzwg-nisha-chavan-2024s-projects.vercel.app)

## Features

- Client-side routing with React Router (`/home`, `/about`, `/resume`, `/achive`)  
- Modern and responsive UI using Material UI components  
- Smooth animations and transitions with Framer Motion  
- Custom 404 page for unmatched routes  
- Optimized production build for performance and fast loading  

## Technologies Used

- **React.js** – For building dynamic and reusable UI components  
- **React Router** – For SPA client-side routing  
- **Material UI** – Pre-built, responsive UI components  
- **Framer Motion** – Smooth animations and transitions  
- **Vercel** – Deployment and hosting platform
